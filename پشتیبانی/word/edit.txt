برای فعال‌کردن ویرایش ردیف (Row Editing) در @mui/x-data-grid باید از Row Editing API استفاده کنی، نه فقط editable: true روی ستون‌ها.

الان در کدت:

ویرایش سلولی (Cell Editing) داری

ولی ویرایش ردیفی کامل (Save / Cancel) فعال نیست

در ادامه دقیق و مرحله‌به‌مرحله می‌گویم چطور درستش کنی 👇

1️⃣ حالت ویرایش ردیفی را فعال کن
باید editMode="row" را به DataGrid اضافه کنی.

<DataGrid
  editMode="row"
  ...
/>
2️⃣ state برای کنترل حالت ویرایش ردیف‌ها
بالای کامپوننت:

const [rowModesModel, setRowModesModel] = useState({});
و به DataGrid اضافه کن:

<DataGrid
  rowModesModel={rowModesModel}
  onRowModesModelChange={setRowModesModel}
  ...
/>
3️⃣ ستون اکشن (ویرایش / ذخیره / لغو)
یک ستون اکشن اضافه کن:

import {
  GridActionsCellItem,
  GridRowModes,
} from "@mui/x-data-grid";
import EditIcon from "@mui/icons-material/Edit";
import SaveIcon from "@mui/icons-material/Save";
import CancelIcon from "@mui/icons-material/Close";
و داخل columns:

{
  field: "actions",
  type: "actions",
  headerName: "عملیات",
  width: 100,
  getActions: ({ id }) => {
    const isInEditMode =
      rowModesModel[id]?.mode === GridRowModes.Edit;

    if (isInEditMode) {
      return [
        <GridActionsCellItem
          icon={<SaveIcon />}
          label="Save"
          onClick={() =>
            setRowModesModel({
              ...rowModesModel,
              [id]: { mode: GridRowModes.View },
            })
          }
        />,
        <GridActionsCellItem
          icon={<CancelIcon />}
          label="Cancel"
          onClick={() =>
            setRowModesModel({
              ...rowModesModel,
              [id]: {
                mode: GridRowModes.View,
                ignoreModifications: true,
              },
            })
          }
        />,
      ];
    }

    return [
      <GridActionsCellItem
        icon={<EditIcon />}
        label="Edit"
        onClick={() =>
          setRowModesModel({
            ...rowModesModel,
            [id]: { mode: GridRowModes.Edit },
          })
        }
      />,
    ];
  },
}
